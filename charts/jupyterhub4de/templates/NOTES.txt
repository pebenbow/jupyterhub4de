jupyterhub4de installed into namespace {{ .Release.Namespace }}.

JupyterHub:
  kubectl -n {{ .Release.Namespace }} port-forward svc/proxy-public 8080:80
  open http://localhost:8080  (DummyAuthenticator — any username, any password)

Dagster webserver:
  kubectl -n {{ .Release.Namespace }} port-forward svc/dagster 3000:3000
  open http://localhost:3000

CloudBeaver (catalog/schema/table explorer, over Spark Thrift Server):
  kubectl -n {{ .Release.Namespace }} port-forward svc/cloudbeaver 8978:8978
  open http://localhost:8978
  First time only (persists on the workspace PVC after): complete the
  setup wizard, add a connection using the Apache Kyuubi driver against
  spark-thriftserver:10000, and grant students access to it. Exact steps
  and why each one is needed: templates/cloudbeaver.yaml.

Hive Metastore health:
  kubectl -n {{ .Release.Namespace }} logs deploy/hive-metastore
  kubectl -n {{ .Release.Namespace }} get pods -l app=hive-metastore

Pipeline code lives on the shared PVC's /code subpath — see
charts/jupyterhub4de/README.md for how to get pipeline scripts onto it.
