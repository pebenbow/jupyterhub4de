# Positron is the student IDE, and course material is Quarto, not .ipynb

Students work in Positron Server (launched from the JupyterLab Launcher via jupyter-positron-server), and lessons ship as Quarto `.qmd` files rather than Jupyter notebooks. code-server stays installed alongside it for comparison. `.qmd` is plain text, so lessons diff and review cleanly. Positron runs `{python}` cells in a persistent console with a Variables pane, and `quarto render` doubles as an end-to-end run of the lesson against the pod's Spark and Hive Metastore. This follows the instructor's Quarto-over-PySpark prototype for DAT 342. The cost is a license dependency: Positron Server only starts with a `license.lic` from Posit (free for academic use). That license is supplied at install time as a Kubernetes Secret, never baked into the published image, and the notebook pod still works without it, minus Positron.
